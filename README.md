# 蓝桥杯 Python 模拟训练平台（本地 OJ）

一个仿蓝桥杯官网风格的在线判题网站，跑在你自己的电脑上：选题、写 Python、提交、立刻判对错，
每题都带题解和参考答案。判题用的是**本机 Python 真实执行**，所以超时、报错、输出不符都能如实反馈，
和考试时的行为一致。

**一句话概况**：84 道题（72 编程 + 12 填空）· 568 个测试点 · 零第三方依赖 · 只监听 `127.0.0.1`。

## 一分钟上手

```bat
git clone https://github.com/LIUZHIYON/lanqiao-oj.git
cd lanqiao-oj
start.bat                       rem 或者 python server\app.py
```

需要 **Python 3.10+**（只用标准库，不用 pip 装任何东西）。启动后黑窗口会打印实际地址，
浏览器自动打开。第一次运行会自动建 `data/oj.db`，进度从零开始。

> **隐私**：做题记录、收藏、模拟赛成绩全部只存在本机 `data/oj.db` 里，已在 `.gitignore` 中排除，
> 不会被提交或推送；代码里也没有任何上报网络的地方。

## 启动细节

**端口被占用怎么办**：OJ 会按 `首选 → 8000 → 8010 → 8020 → 8030 → 8050 → 8080 → 8123 → 8888`
的顺序自动往后找，窗口里会显示「端口 8000 已被其它程序占用，自动改用 8010」，按那个地址用即可。
想固定端口就显式指定：

```bat
python server\app.py --port 9000
```

其它说明：

- 只监听 `127.0.0.1`，不会暴露到局域网
- 不需要联网，不装任何第三方库（Python 3.10+ 标准库即可）
- 黑窗口里的中文若显示乱码，是因为 cmd 默认 GBK；`start.bat` 已自动执行 `chcp 65001`，
  若你直接命令行启动，可先运行 `chcp 65001`

### 再加题（不用改任何现有代码）

在 `generator/extra/` 下新建一个文件（照 `_TEMPLATE.py` 写），声明 `PROG_META` / `FILL_META` /
`prog_cases()`，把参考解放进 `generator/reference/`，然后：

```bat
python generator\build_problems.py --only p63 p64      rem 只构建这一批
python generator\self_check.py --only p63 p64          rem 只自检这一批（必须全 AC）
python generator\build_problems.py                     rem 全量重建，验证幂等
```

服务会在下次刷新页面时自动读到新题（按文件修改时间热加载），不用重启。

## 收藏不会做的题

题目页题号旁边有「☆ 收藏这题」，卡住就先点一下，不用当场死磕。收藏之后有三个地方能用到：

| 位置 | 作用 |
|---|---|
| 题库页 → 筛选「只看收藏」 | 只列出收藏过的题（网址 `problems?star=1`） |
| 题库页 → 排序「收藏的排前面」 | 收藏题顶到最上面，其它照常刷 |
| 题库每行标题前的 ★/☆ | 不进入题目就能直接收藏/取消 |
| 首页「我的收藏」 | 显示共收藏几道、几道还没做出来，一键跳到收藏列表 |

收藏存在 `data/oj.db` 的 `starred` 表里，和提交记录一起，换浏览器打开同一个服务也能看到。
「我的提交」页的清空练习记录会连收藏一起清掉。

## 判题规则

- **编程题**：服务端把你的代码写成 `submission.py`，在 `data/runs/` 的隔离目录里运行，
  喂标准输入、比对标准输出。比对时忽略每行行尾空格与结尾空行，其余必须完全一致。
- **结果填空题**：只提交答案数字/字符串，比对通过即得分（答错会给一句易错提醒）。
- 状态含义：`AC` 通过 / `WA` 答案错误 / `TLE` 超时 / `RE` 运行错误（附 traceback 与出错行）
  / `CE` 语法错误 / `OLE` 输出过长。
- 每题多个测试点，隐藏测试点只显示名字、分值和结果，不给输入输出，避免照着答案凑。
- 默认时限 2 秒/测试点，可在题目 JSON 的 `limits.time_ms` 单独设置。

## 目录结构

```
lanqiao-oj/
├── start.bat                  双击启动
├── server/                    后端（全部标准库实现）
│   ├── app.py                 HTTP 服务与 API 路由
│   ├── judge.py               判题引擎：执行、超时、比对、状态归类
│   └── store.py               题库加载 + sqlite 记录（提交/题解查阅/比赛）
├── web/                       前端页面与样式脚本
│   ├── index.html  problems.html  problem.html  submissions.html  contest.html
│   └── assets/oj.css  oj.js
├── problems/                  题库，一题一个 JSON（84 道）
├── generator/                 题库构建与自检
│   ├── reference/             每题的参考解（构建时用它生成标准输出）
│   ├── extra/                 追加题库（插件式）：easy_batch / mid_batch / bridge_batch / _TEMPLATE
│   ├── build_problems.py      跑参考解 → 生成 problems/*.json 的 expected
│   └── self_check.py          用参考解判自己的题，必须全 AC
├── data/                      运行时生成：oj.db（记录）与 runs/（判题临时目录）
└── docs/contract.md           前后端与题库的字段契约
```

## 重新生成 / 校验题库

```bat
python generator\build_problems.py    rem 用参考解真实运行生成标准输出
python generator\self_check.py        rem 参考解自判，全部 AC 才算题库可用
```

## 加自己的题

在 `problems/` 复制一份现有 JSON 改字段即可，字段含义见 `docs/contract.md`。
编程题的 `expected` 建议不要手写——在 `generator/reference/` 放一个参考解，
用 `build_problems.py` 跑出来，避免把自己算错的答案当成标准答案。

## 清空进度

关掉服务后删除 `data/oj.db`，或在「我的提交」页面点「清空练习记录」，所有提交历史与统计归零。

## 题源与答案口径

题目以蓝桥杯 Python 组历年真题与高频考点为蓝本重新命题/改编，填空与编程的答案**不是手写的**：
每道编程题在 `generator/reference/` 有一个参考解，构建时真实运行生成标准输出，且每个参考解都配了
第二条独立算法互验；填空题的 `generator/fill_scripts/` 脚本负责算出答案。
`generator/self_check.py` 会拿参考解去判自己出的题，全 AC 才算这批题可用。

## 配套讲义

每题标了讲义章节（`chapter` 字段）与参考脚本路径（`solution.reference`）。配套讲义是另一个本地项目
`lanqiao-cup-python`（零基础冲刺讲义，17 页 HTML + A5 PDF），两者按章节号互相对应；
没有讲义也不影响使用，题解在每个题目页的「题解」区里就有。判题结果里的 RE/CE 详情会告诉你哪一行错了。
